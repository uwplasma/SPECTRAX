Getting started
=====

.. _installation:

Installation
------------

To use SPECTRAX, you can clone the repository
and install it using the following command:

.. code-block:: console

    $ git clone https://github.com/uwplasma/spectrax.git
    $ cd spectrax
    $ pip install .

Run an example
--------------

A case is one TOML file; the input reference and the Python interface are in the README (``Usage`` and
``Input File Format``).

.. code-block:: console

    spectrax Examples/input_1D_two_stream.toml

More examples are in the `Examples` folder.
